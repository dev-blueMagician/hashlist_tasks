What the RTL · terminal shell sets up

A change to a Verilog block, made the way an RTL engineer makes it: a shell in a Debian box with Icarus Verilog 13, Verilator 5.048 and make, your design, its smoke testbench and spec. The agent edits the design files and submits. The grader, already written, checks they are synthesizable RTL that names nothing outside themselves and cannot print a check or end a run, then runs each of your withheld testbenches in verifier/rtl.json, at the parameters you name, on Icarus Verilog and on Verilator at 16 random power-up states, each run with a fresh stimulus seed: a check passes only if it passes on every run. Checks the design already passed as handed over go in `must`: failing one scores 0, and they pay nothing.

Tools

bash(command), view_image(path), submit(notes)

Scoring

your withheld testbenches, check by check, on the design it saved; reward 0.00 to 1.00, the design as handed over 0.00

Needs

a working design and a change request, or a design with a bug, and the design changed

The files this task is made of

agent/PROMPT.md you write it The change request, the spec, and what is graded

environment/Dockerfile written for you Debian with Icarus Verilog 13 and Verilator 5.048, and your files under /app/data

environment/data/design.v you write it The design as handed over

environment/data/Makefile you write it Runs the smoke testbench

references/gold.py you write it [title: Never copied into the container the agent works in] withheld Writes the changed design. It has to score 1.00

references/naive_base.py you write it [title: Never copied into the container the agent works in] withheld Writes the design as handed over. It has to score 0.00

references/naive_a.py you write it [title: Never copied into the container the agent works in] withheld The most likely wrong change

verifier/rtl.json you write it [title: Never copied into the container the agent works in] withheld The design files, `must`, and each testbench with its parameters and the checks it prints

verifier/report.py written for you [title: Never copied into the container the agent works in] withheld The grader: writes the reward and each check

/app/data/design.v the agent writes it The design the agent changes
