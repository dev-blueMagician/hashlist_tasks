Scripts before and after the model optional, hidden from the model

Run in the box as root, in the workdir: one before the model's first step, one after its last and before the answer file is read. The correct answer and each common mistake run with them too. Use them to set up the starting state, or to pack what the model changed into the answer file, so the model is not graded on packing it. A setup that fails stops the run as an error. A teardown that fails is no answer, a score of 0, as it fails on what the run left; Verify shows it on your correct answer first. What setup makes under the workdir is given to the model's user, so the model can edit it; anything it makes elsewhere stays root's. A teardown that writes the answer file replaces a correct answer typed as that file: write your answers as scripts that change what teardown packs.
