HDL_mw3o014d_Trung (task-mw3o014d) - builder round 2, with the plan runner
=========================================================================
This zip holds:
  HDL_mw3o014d_Trung/     the task folder, only the files this round needs
  dop-builder-helper/     the extension, version 2.2

1. Unzip next to (or over) your earlier copy on the VM.
2. Update the extension: chrome://extensions, "Load unpacked" on the
   dop-builder-helper folder from this zip (or replace the old folder's
   files with these and press the reload arrow). The card must say 2.2.
3. In the extension popup, Choose folder: pick HDL_mw3o014d_Trung (the task
   folder, not author).
4. Open the task in the builder, in one tab only.
5. Run a plan -> Preview -> Run. It sets the step limit to 500 in 2.2, runs
   Try the box in 2.4 (a few minutes; it does not submit), then saves every
   section. Never open section 7 or press Run.

Bring back to the PC: the whole folder HDL_mw3o014d_Trung/author/round2/
(pages and the plan log). Put it at the same place on the PC, then say "done".
