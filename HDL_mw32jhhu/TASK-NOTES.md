Grader rules (report.py):

- Lint on the dut files, with comments and strings removed. It rejects:
  - any directive except `` `timescale `` and `` `default_nettype `` (so no `` `define ``, `` `include `` or `` `ifdef ``);
  - any system task except `$signed`, `$unsigned` and `$clog2`;
  - `initial`, `force`/`release`/`deassign`, `defparam`/`bind`, `import`/`export`, `wait`/`fork`/`forever`/`while`/`event`, and `->`;
  - any backslash (escaped identifier), a hierarchical name, a `primitive`;
  - any `#` outside a module header's `#(` or a named override `#(.`, so a positional override `#(8)` counts as a delay;
  - an event control other than `@*` or a posedge/negedge list, or one that does not open an `always`;
  - a register declared with a value, and both edges of one signal.

A check passes only if every run of every bench that names it printed PASS. A missing DONE, a timeout or a signal fails the run's checks.

- Reward is 0 if lint, elaboration or any `must` check fails. Otherwise it is the share of the non-`must` checks that pass. So `naive_base` = 0.00 means every paying check must fail on the base design.
